# Roadmap

The implementation is evidence-gated. Phase 0 establishes tooling; Phase 1 builds core pairing and adapters; Phase 2 reproduces the underlying thesis and stops for a human Gate 1 decision.

V1 excludes hybrid RRF retrieval, multiple adapter routing, live migration, cross-provider adapters, LLM/reranker testing, a compliance platform, and hosted SaaS.
